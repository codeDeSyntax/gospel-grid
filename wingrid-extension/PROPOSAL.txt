1. PROBLEM STATEMENT
================================================================================

PROBLEM 1: Limited Multi-Window Sharing in Online Meetings

When you're doing remote presentations or online meetings, you often need to 
show multiple things at once - like your code editor, terminal output, browser 
with documentation, and maybe a design tool. But here's the issue: most 
meeting platforms (Zoom, Teams, Google Meet) only let you share one window at 
a time. 

Sure, you can switch between windows, but that's clunky and breaks the flow. 
Your audience loses context every time you switch. What we really need is a 
way to composite multiple windows into a single view and share that entire 
layout as one stream. That way, your audience sees everything you're working 
with simultaneously, just like you do on your multi-monitor setup.


PROBLEM 2: The Display Mode Switching Nightmare

This one's particularly annoying if you use presentation apps or any software 
that requires specific display configurations. Let's say you have a laptop 
connected to a projector or external monitor. Some apps work great when you're 
in "duplicate" mode (both screens showing the same thing), others need 
"extend" mode (separate content on each screen).

The real pain comes when different apps have different requirements. You might 
have a Bible presentation app that needs Display 1 as primary, then switch to 
another app that needs Display 2 as primary. So you're constantly going into 
Windows display settings, switching between duplicate and extend, changing 
which display is primary, and dealing with all your windows jumping around and 
losing their positions.

It's a workflow killer. Every time you switch apps, you're spending time 
reconfiguring displays instead of actually doing your work.


================================================================================
2. AIM AND OBJECTIVES
================================================================================

AIM:

The main goal here is to solve both problems with a single solution that gives 
you full control over multi-window compositing and intelligent display 
management without having to mess with Windows display settings.

OBJECTIVES:

1. Build a desktop app (WinGrid) that lets you capture multiple windows and 
   composite them into different layouts (2x2 grid, side-by-side, etc.) for 
   sharing in online meetings

2. Implement intelligent display detection that automatically places windows 
   on the correct display (internal laptop screen vs external monitor/
   projector) regardless of which display is set as "primary" in Windows

3. Eliminate the need to constantly switch between "duplicate" and "extend" 
   display modes - the app handles it automatically by detecting display 
   properties

4. Create a published projection window that mirrors your composite to the 
   external display without requiring display mode changes

5. Build a browser extension version that provides multi-window compositing 
   for users who prefer staying in the browser or can't install desktop apps

6. Make both solutions work together - desktop for advanced display management 
   and projection, browser extension for quick multi-window sharing in web-
   based meetings

2. Check which display is primary

4. PROPOSED SOLUTION - DESKTOP APP
================================================================================

HOW IT WORKS:

The desktop app provides two windows that work together:

Controller Window:
- Shows on your laptop screen
- Displays thumbnails of all captured windows
- Lets you choose how to arrange them (grid, side-by-side, etc.)
- Control panel for selecting themes and settings

Projection Window:
- Automatically appears on your external monitor or projector
- Shows the live combined view of all your selected windows
- Full-screen presentation display
- No manual configuration needed - it just goes to the right screen

INTELLIGENT DISPLAY MANAGEMENT:

The app automatically figures out which screen is your laptop and which is 
your external display. It doesn't matter what Windows display settings you 
have - the app detects the displays and puts each window where it belongs.

This works regardless of:
- Which display Windows thinks is "primary"
- Whether you're in extend or duplicate mode
- How many times you've switched between different apps
- What display configurations you've used before

USING THE APP:

1. Capture the windows you want to show
2. Choose a layout (2x2 grid, side-by-side, etc.)
3. See the preview on your controller screen
4. Toggle ON - the projection window opens on your external display
5. Share that projection window in your online meeting, or just use it for 
   local presentations
6. Your audience sees all your windows arranged together in one clean view


================================================================================
5. PROPOSED SOLUTION - BROWSER EXTENSION
================================================================================

PURPOSE:

The browser extension provides the same multi-window compositing capability 
but works entirely in your browser. Use it when:
- You want to stay in the browser without switching to a desktop app
- You're on a machine where you can't install software
- You just need to share multiple windows in a web meeting
- You don't need the automatic display management features

HOW IT WORKS:

Same workflow as the desktop app:
1. Click the extension icon to open the control page
2. Click "Add Window" and select which windows to capture (same way Zoom 
   asks you to pick a window)
3. Your captured windows show as thumbnails on the left
4. Choose your layout and see the preview on the right
5. Toggle ON to open the published window with your composite
6. Share that published window in your video call

WHAT'S DIFFERENT:

The browser version focuses purely on multi-window sharing. It doesn't have 
the automatic display detection since browsers don't control physical 
monitors. You'll need to manually select each window you want to capture, and 
it works best for online meetings rather than local projection setups.
